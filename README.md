# 🐍 Desafios de Lógica de Programação em Python

Repositório dedicado à prática e consolidação dos fundamentos da linguagem **Python** e lógica de programação. O projeto conta com exercícios resolvidos e um **menu interativo** que centraliza e executa todos os desafios.

---

## 🎯 Conceitos Praticados
* Estruturas condicionais (`if`, `elif`, `else`)
* Laços de repetição (`while` e *list comprehension*)
* Manipulação de listas e operações matemáticas
* Modularização e importação de arquivos (`import`)
* Funções (`def`) e entrada/saída de dados no terminal

---

## 📂 Estrutura do Projeto

| Arquivo | Descrição do Desafio |
| :--- | :--- |
| **`desafio.py`** | Lê $N$ números inteiros e identifica o **segundo maior** valor digitado. |
| **`desafio2.py`** | Analisa uma sequência de números e contabiliza quantos são **positivos e negativos**. |
| **`desafio3.py`** | Armazena valores em uma lista, calcula a **soma, a média** e conta quantos números ficaram **acima da média**. |
| **`desafio4.py`** | Separa números **pares e ímpares**, exibindo a quantidade e a soma total de cada grupo. |
| **`desafio5.py`** | Lê uma sequência de valores e retorna a **soma, a média e o maior** número informado. |
| **`desafio6.py`** | Calculadora interativa onde o usuário escolhe calcular a **soma, média, maior ou menor** valor de uma lista de números. |
| **`desafio7.py`** | **Menu Principal (Hub):** Importa todos os módulos anteriores e permite executar qualquer desafio em loop. |

---

## 🚀 Como Executar o Projeto

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd desafios_python
   ```

3. **Execute o menu principal:**
   ```bash
   python desafio7.py
   ```
